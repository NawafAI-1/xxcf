Sea Around Us -- Reconstructed Catch Data, GFCM RFMO Area

Sea Around Us (SAU) reconstructed marine fisheries catch data aggregated to the General Fisheries Commission for the Mediterranean (GFCM) Regional Fisheries Management Organization (RFMO) area, 1950-2019. On inspection, this extract's only area_name value is 'GFCM' -- a Mediterranean and Black Sea RFMO -- so despite being stored in the same 'eco reomote' folder as the Red-Sea-specific SAU EEZ/MEOW extracts, its actual coverage is NOT the Red Sea. Included here for completeness per instructions but flagged as likely mis-scoped or downloaded as a broader reference/comparison set rather than a Red-Sea layer.

Known issues (4)

  • •IMPORTANT: this extract's only area_name is 'GFCM' (Mediterranean/Black Sea), not a Red Sea RFMO -- consider excluding from a strictly Red-Sea-scoped catalog, or clearly labeling as an out-of-basin reference/comparison dataset. Kept in per task instructions to flag honestly rather than silently drop.
  • •'RFMO 4' in the filename likely refers to the SAU internal RFMO ID, not '4 RFMOs' worth of content -- only GFCM rows were found in this file; not independently confirmed against the full 1.3M-row file (only spot-checked).
  • •bbox/subbasins fields are not meaningful for this record given the mismatch above; bbox given is a rough Mediterranean+Black Sea box, not the Red Sea.
  • •A duplicate .zip archive also exists alongside it (SAU RFMO 4 v50-1.zip) -- not catalogued separately.
