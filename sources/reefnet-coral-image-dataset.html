ReefNet: Global Coral Reef Image Annotation Dataset (v1.0)

ReefNet is a large-scale, taxonomically enriched collection of annotated coral reef images compiled from many CoralNet sources worldwide, built for training and benchmarking machine-learning coral classification models. It includes a consolidated global label set, per-source metadata, and a dedicated Red Sea test partition (the 'RSG-TestDataset') contributed by Red Sea Global, collected in the Al-Wajh lagoon (~26.4N, 36.4E) in 2022 and used as a held-out evaluation set in the ReefNet paper. The dataset as a whole is global in scope; only the RSG-TestDataset partition is Red-Sea-specific.

Known issues (4)

  • •Only the RSG-TestDataset partition (17,870 point annotations across images captured 2022-03) is confirmed Red-Sea-specific; the bulk of the ~2.7 GB All_ReefNet_annotations.csv covers reef sites worldwide and was not filtered to the Red Sea for this catalog entry.
  • •n_rows for All_ReefNet_annotations.csv and several metadata/label-mapping files were not counted (multi-GB file, no spreadsheet-reading tool available in this environment) -- left as 0/unknown, verify before publishing.
  • •arXiv preprint citation ID was blank in the source README ('arXiv:XXXX.XXXXX') at time of cataloging; DOI intentionally left null.
  • •access.tier set to 'public' based on the Hugging Face release and CC BY-NC-SA license, but the copy inside KAUST - DATA may be an internal working mirror -- confirm before treating the local file paths as externally shareable.
